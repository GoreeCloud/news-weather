# GoreeCloud News & Weather — Planned Features

This file records planned capability and does not claim implementation.

## 0.1.0 Development target

### Product shell
- Home, News, and Weather primary navigation.
- Search and Settings actions.
- Light, dark, and system themes.
- Glaze UI integration.
- Accessibility foundations.
- First-use onboarding.
- Optional contextual hints with user control.

### Home
- Current temperature and weather condition.
- Important active alerts.
- Today's high and low.
- Small precipitation indicator when useful.
- Approximately six to ten recent headlines from selected sources.
- Bounded content; no infinite dashboard.

### News
- RSS and Atom through GoreeCloud Feeds.
- Source subscriptions and management.
- OPML import/export.
- Basic folders and categories.
- Chronological ordering by default.
- Read/unread state.
- Bookmarks.
- Basic search and source filtering.
- Useful date filtering.
- Bounded offline reading cache where practical.

### Weather
- Manual locations.
- Optional explicit current-location action.
- One working provider path behind the GoreeCloud weather adapter.
- Current conditions.
- Feels-like temperature where available.
- Today's forecast.
- Hourly forecast.
- Seven-day forecast.
- Precipitation probability and expected precipitation where available.
- Wind speed/direction.
- Humidity, sunrise, and sunset where useful.
- Official severe-weather alerts where supported.
- Last-successful forecast cache with visible staleness timestamp.

### Settings
- News sources and folders.
- Saved/default weather locations.
- Temperature, wind, and precipitation units.
- Notification preferences.
- Theme and text size.
- Refresh interval and offline-cache limits.
- Privacy permissions.
- Synchronization preferences.
- Import/export.
- Contextual-hints control.

### Notifications
- Severe-weather notifications only after explicit enablement.
- Optional news notifications for explicitly selected sources.
- No engagement reminders.

### Platforms
- Android Development build.
- Web Development build.
- Linux Development build.
- Windows Development build.

## Intentionally non-blocking for 0.1.0

- AI summaries.
- Recommendation algorithms.
- Weather radar.
- Social comments or reactions.
- Video-news feeds.
- Personalized discovery.
- Home-screen widgets.
- Multi-provider weather switching.
- Full account synchronization.
- Advanced weather charts.
- Advanced analytics.
